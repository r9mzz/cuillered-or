# DJ Hako

Site de DJ Hako, DJ de mariage à Lyon et en Rhône-Alpes. Site statique (HTML, CSS, JS), publié avec GitHub Pages.

- `index.html` : la page du site
- `mentions-legales.html` : à compléter (nom, SIRET, adresse, hébergeur)
- `img/` : photos
- `liquid-glass.js`, `verre-liquide.js` : effet verre de la barre et des panneaux

L'ancien site de La Cuillère d'Or est conservé sur la branche `sauvegarde-cuillere-dor-2026-11-08`.

## Ziana So Chic

Le dossier `ziana-so-chic/` contient le site de Ziana So Chic (négafa, Paris), publié à l'adresse `/cuillered-or/ziana-so-chic/`. Il est indépendant du site DJ Hako.
